# Upgrade Premium (Paquete Bodas)

Es el **paquete estándar más extras**. Incluye el programa de tres días y, además: table styling (copas, plato base y plaqué de color), upgrade de barra de servicio y DJ booth, barra libre nacional, sillas premium, plafón de diseño y menú 100% res.

Los precios salen del catálogo **por tramo de invitados** (cien, ciento cincuenta, doscientos, doscientos cincuenta, trescientos). Otros tamaños los confirma un asesor. No incluye IVA ni tramitología.
